# Codyssey 개발 워크스테이션 구축

## 프로젝트 소개
윈도우 환경에서 개발에 필요한 도구들을 설치하고 설정하는 미션입니다.

## 설치한 도구
- **Git** : 버전 관리 도구 (v2.46.0)
- **Docker Desktop** : 컨테이너 실행 도구 (v27.0.3)
- **WSL2** : 윈도우에서 리눅스를 쓰기 위한 기능

## 진행 내용
- Git 설치 및 설정 완료
- Docker Desktop 설치 및 실행 확인
- GitHub 저장소 연결 완료

## 느낀 점
경영학부 출신이지만 하나씩 따라하니 개발 환경을 구축할 수 있었다!
